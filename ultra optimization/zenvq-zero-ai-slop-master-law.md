## 🎨 2. PILLAR I: VISUAL & UI/UX ZERO-SLOP DISCIPLINE

### Rule 1.1: Zero Flat CSS Hardware Mockups (100% Strict)
- **BANNED:** Never use flat CSS divs or simple bordered rectangles with rounded corners to represent laptops, tablets, or phones.
- **MANDATED:** Always pull authentic 3D hardware components via Shadcn MCP, 21st.dev, or Aceternity registry (`macbook-scroll`, `container-scroll-animation`, `multi-device-triad`). Hardware frames must feature realistic bezel depth, camera notches, glass reflections and dynamic perspective transforms (`rotateX`, `translateZ`, `scale`).

### Rule 1.2: Zero Text Logos Inside Bordered Boxes
- **BANNED:** Never render client, partner, or tech stack logos as plain typography inside bordered boxes (e.g. `<div>Stripe</div>` or `<button>Shopify</button>`).
- **MANDATED:** Always use authentic inline monochrome SVG vector paths (`fill-zinc-500 hover:fill-white transition-colors`) with linear gradient edge masks (`from-zinc-950 via-transparent to-zinc-950`) on smooth hardware-accelerated marquees.

### Rule 1.3: Zero Generic AI Gradients & Muddy Shadows
- **BANNED:** Never use generic purple-indigo gradients (`from-indigo-500 to-purple-600`), raw neon blues (`bg-blue-600`), or heavy dirty drop shadows (`shadow-2xl`).
- **MANDATED (ZenVQ Dark Luxury System):**
  - **Canvas:** `#09090B` (`bg-zinc-950`)
  - **Elevated Cards:** `rgba(24, 24, 27, 0.65)` (`bg-zinc-900/65 backdrop-blur-xl`)
  - **Hairline Borders:** `1px solid rgba(255, 255, 255, 0.08)` (`border-white/[0.08]`)
  - **1px Top Specular Edge Highlight:** Every card must feature a 1px top edge glow (`bg-gradient-to-r from-transparent via-white/25 to-transparent h-px w-full`).
  - **Accent Glow:** Controlled emerald/cyan bloom (`#00E599` / `#00D2B4`) with subtle opacity (`rgba(0, 229, 153, 0.14)`).

### Rule 1.4: Zero Creepy AI Avatars & Stock Characters
- **BANNED:** Never embed glossy AI-generated human faces, weird plastic 3D avatar heads, or floating generic shapes.
- **MANDATED:** Use clean monochrome vector monograms, executive initials, verified architectural schematics, or device screen captures.

## ✍️ 3. PILLAR II: COPYWRITING & NARRATIVE ZERO-SLOP DISCIPLINE

### Rule 2.1: Banned AI Buzzwords & Cliches (Instant Rejection)
The following terms and phrases are **STRICTLY BANNED** from all copy, headers, badges, metadata and bullet points:
- ❌ *"Delve into"* / *"Let's dive deep"*
- ❌ *"In today's fast-paced digital landscape/world"*
- ❌ *"Synergistic paradigm"* / *"Revolutionary transformative synergy"*
- ❌ *"Unlock the power of"* / *"Harness the potential"*
- ❌ *"Holistic turnkey bespoke solutions"*
- ❌ *"Game-changing"* / *"Next-gen cutting-edge disruption"*
- ❌ *"Tapestry"* / *"Testament to"* / *"Beacon of excellence"*

### Rule 2.2: Plain-English High-Conversion Clarity
- **MANDATED:** Replace all pretentious fluff with punchy, plain-English sentences that a non-technical founder or busy executive grasps in 2 seconds.
- Clearly describe **WHAT** we build, **HOW** we build it and **THE EXACT VALUE** delivered.

### Rule 2.3: Zero Circular Narrative Fluff
- **BANNED:** Looping the same benefit claim across 4 different sections with slightly modified phrasing.
- **MANDATED:** Every section, card and bullet must communicate a distinct, actionable deliverable (e.g. Squad specialization, 15-Minute SLA, 3-Person Pod structure, OWASP hardening, Cloudflare edge routing).

### Rule 2.4: Space-Efficient Copy & Scannability
- Paragraphs must never exceed 3-4 lines.
- Use scannable technical badges, index counters (`[01]`, `[02]`) and bulleted proof metrics.

## 💻 4. PILLAR III: FULL-STACK CODE & ARCHITECTURAL ZERO-SLOP DISCIPLINE

### Rule 3.1: Zero Blanket "use client" Dumping
- **BANNED:** Slapping `"use client"` at the top of page layouts, top-level containers, or wrapper components.
- **MANDATED:** Keep Server Components by default. Push `"use client"` down to leaf-level interactive micro-islands (modals, buttons, dropdowns, canvas animation). Zero hydration mismatches.

### Rule 3.2: Heading Hierarchy & Semantic Integrity
- **BANNED:** Multiple `<h1>` tags on a page, skipping heading levels (e.g. `<h1>` followed by `<h4>`), or using headings for styling.
- **MANDATED:** Exactly ONE semantic `<h1>` per page. Decorative overlays or specular reflection text duplicates must use `<span aria-hidden="true">` to preserve perfect SEO semantics.

### Rule 3.3: Image & Asset Optimization
- **BANNED:** Unsized `<img>` tags causing Cumulative Layout Shift (CLS), raw multi-megabyte PNGs, unoptimized GIFs.
- **MANDATED:** Next.js `<Image>` with explicit `width`, `height`, `priority` for above-the-fold assets, WebP/AVIF formats, and `sizes` attributes for responsive srcset.

### Rule 3.4: Bundle Discipline & Tree-Shaking
- **BANNED:** Blanket wildcard imports (`import * as Icons from 'lucide-react'`).
- **MANDATED:** Named, granular imports (`import { Shield, Cpu } from 'lucide-react'`) ensuring zero bundle bloat and sub-50ms INP.
