## 🧹 4. UNIVERSAL CONTENT MERGING & DEDUPLICATION RULES

To keep everything clean, maintainable and crystal clear, the following deduplication rules are enforced across all repositories and platforms:

### Rule 4.1: Single Domain Policy (Zero Duplicate Aliases)
- **Law:** Never maintain multiple domains pointing to the same code or utility.
- **Example Applied:** `mediadrop.zenvq.com` was permanently merged into `tools.zenvq.com/mediadrop`. Any old CNAME or Pages alias is deleted to eliminate confusion, avoid duplicate SEO penalties and centralize authority.

### Rule 4.2: Single Source of Truth for Rules & Policies
- **Law:** Do not copy-paste identical markdown rules across dozens of folders.
- **Governance:** 
  - Master rules live permanently in `git hub & cloudflare master rules\`.
  - All project agents reference these canonical documents rather than keeping out-of-date local clones.

### Rule 4.3: Credential Sanitization (Wincred Consolidation)
- **Law:** Eradicate duplicate and plain-text Personal Access Tokens (`ghp_...`) embedded in `.git/config` URLs.
- **Action:** All repositories must point to pure HTTPS URLs (`https://github.com/PusonDev/<Repo>.git`) authenticated solely through Windows Credential Manager (`wincred`).

### Rule 4.4: Zero Dead Legacy Code or Duplicate Folders
- Temporary folders, unlinked copies and abandoned test directories inside `03-Templates-Hub` or `ZenVQ-Tools` must either be linked to their true parent or cleanly archived.
- Every directory must have a clear parent and grandparent in the matrix.
